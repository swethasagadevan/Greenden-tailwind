# 🌿 Plant Shop Website

A simple and responsive plant shopping website built using **HTML** and **Tailwind CSS**. The site includes three main pages:

- 🏠 Home
- 🛒 Products
- 📞 Contact

---
## 📸 Demo

https://swethasagadevan.github.io/Greenden-tailwind/

## 🚀 Features

- Responsive design using Tailwind CSS
- Clean and modern UI
- Product showcase section
- Contact form for inquiries

---

## 📁 Project Structure


- index.html # Home page
- products.html # Products page
- contact.html # Contact page
- assets # Images, icons, etc.
